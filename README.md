# ts-graphviz.github.io

**The source of this website has moved to the [`website/`](https://github.com/ts-graphviz/ts-graphviz/tree/main/website) directory of [ts-graphviz/ts-graphviz](https://github.com/ts-graphviz/ts-graphviz).**

Docs and code now change in the same pull request there, and the API reference is built from the same commit. Please open issues and pull requests about the website in [ts-graphviz/ts-graphviz](https://github.com/ts-graphviz/ts-graphviz/issues).

This repository remains as the deployment target of https://ts-graphviz.github.io/: the `Website` workflow of ts-graphviz/ts-graphviz pushes the built site to the `gh-pages` branch, which GitHub Pages serves. The files on `main` are kept for history only and are no longer built.
